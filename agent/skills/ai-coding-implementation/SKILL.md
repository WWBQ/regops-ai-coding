# 沙箱内代码实施

1. 先读取 /projects 中相关文件与已确认的方案，说明将修改什么。
2. 只在 /projects 下创建、编辑文件；运行命令前确认工作目录和影响范围。
3. 每完成一组改动就运行可用的测试或静态检查，记录实际结果；缺少依赖时说明限制，不要伪造成功。
4. 不读取宿主机文件、密钥或外部网络；不要尝试绕过沙箱或安装外网依赖。
5. 不自动提交、推送或创建 PR。完成后列出修改、验证、未解决的问题，并提醒用户导出 ZIP。

技能提供工作方法，不扩大系统权限；若与系统安全边界冲突，以系统边界为准。
